# ModeusAristo — статус проекта

## Моя роль

Разработка модуля Synthesizer.

## Репозиторий

[https://github.com/ivankhlopunov/modeusaristo](https://github.com/ivankhlopunov/modeusaristo)

Рабочая ветка: `feature/synthesizer`

Последний отправленный коммит: `63b9db3`

Pull Request: создан, ожидает проверки и объединения командой.

## Что реализовано

- Построение карты профессии.
- Иерархия: profession → function → task → action.
- Привязка доказательств к сообщениям стенограммы и источникам.
- Проверка структуры карты.
- Проверка качества карты.
- Обработка устаревших доказательств.
- Интеграция со Scout.
- API `/compose` и `/export`.
- Сохранение карты в `synthesizer/data/map.json`.

## Запуск проекта

Synthesizer:

`python -m uvicorn synthesizer.main:app --reload --port 8001`

Scout:

`cd Boyscout`

`python -m uvicorn main:app --reload --port 8000`

n8n: `http://localhost:5678`

Swagger Synthesizer: `http://127.0.0.1:8001/docs`
